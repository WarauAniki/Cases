# COMPAS-3D-Examples

Этот репозиторий содержит примеры 3D-моделей, созданных с использованием COMPAS и других инструментов для работы с 3D-графикой. Здесь вы найдете различные примеры моделей, включая руки, колеса и волновые передачи, а также связанные проектные файлы.

## Примеры файлов

- **Hand-COMPAS-3D.png**: Скриншот 3D-модели руки.
- **Palm-with-fingers.a3d**: 3D-модель ладони с пальцами в формате `.a3d`.
- **Wheel.a3d**: 3D-модель колеса в формате `.a3d`.
- **Wave_transmission_with_intermediate_rolling_elements.png**: Скриншот модели волновой передачи с промежуточными элементами качения.
- **Wheel.stl**: 3D-модель колеса в формате `.stl`.
- **.gitignore**: Конфигурация игнорирования файлов для Git
- **RegulatorWithPID.ino**: Программа стабилизации устройства в невесомости с PID-регулятором
- **Points_example.png**: Пример расчётных точек для волнового редуктора
- **Wave_reduct_calculation.ino**: Программа расчёта точек волнового редуктора
- **Schematic Плата управления манипуляторомх.pdf**: Принципиальная схема платы управления
- **Общий вид(с корпусом).pdf**: Чертёж общего вида устройства
- **Плата управления манипулятором(краткое описание функционала).pdf**: Описание функционала платы
- **ПРИЛОЖЕНИЕ(1 лист спец по эл-там).pdf**: Спецификация электронных компонентов
- **Принципиальная схема.pdf**: Принципиальная электрическая схема
- **Сборочый чертеж(виды сверху вправа итд).pdf**: Сборочный чертёж платы
- **Чертеж платы(трасс, отверстия).pdf**: Чертеж печатной платы
